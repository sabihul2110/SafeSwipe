# SafeSwipe — Project Scope

## What is SafeSwipe?
SafeSwipe is a system that looks at credit card transactions and tries to flag ones that look fraudulent. It's built as a full learning project — we're treating it like a real product, but it started as a way to learn how production systems are actually built and shipped.

## What we're trying to achieve
- A working system that can take transaction data and predict whether a transaction is likely fraud.
- A clean separation between the data/ML side and the backend/API side, so both can be worked on independently.
- Documentation and process that's good enough that a new person could join the project and understand it without asking us directly.

## What's explicitly out of scope (for now)
- Real bank integrations or handling real customer data.
- Regulatory/compliance requirements that a real bank-facing product would need.
- Mobile apps — web only, for now.

## Status
This document will evolve. Right now it's a starting point, not a locked spec.
