# SafeSwipe

SafeSwipe is a credit card fraud detection system, built as a full-stack, ML-integrated platform.

## Project Status
In active development — currently in the foundational/architecture phase.

## Documentation

All architecture decisions, setup guides, and specifications live in the [`docs/`](./docs) directory. Start there if you want to understand how the system is designed and why.

## Getting Started

See [`docs/setup.md`](./docs/setup.md) for full setup instructions for the backend, frontend, and ML pipeline.
For running a live demo, see [`docs/demo_guide.md`](./docs/demo_guide.md).
