# SafeSwipe Backend

This is the FastAPI backend for SafeSwipe. It exposes the API that the frontend talks to, and will eventually serve the ML model's predictions.

## Status
Scaffolding only — no endpoints written yet.

## Stack
- Python 3
- FastAPI
- Uvicorn (dev server)
